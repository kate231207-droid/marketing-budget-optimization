# Marketing Budget Optimization

Linear programming project that allocates a $10 million marketing budget
across 10 advertising platforms using Python and Gurobi.

## Analysis

- Optimized allocations under two ROI scenarios
- Compared the opportunity cost of using an incorrect ROI assumption
- Performed objective-coefficient sensitivity analysis
- Modeled monthly budget reinvestment
- Evaluated month-to-month allocation stability

## Key Results

- Optimal expected return: $456,000
- Opportunity cost under an incorrect allocation: $192,000–$204,000
- Budget after monthly reinvestment: approximately $12.69 million
- The unconstrained monthly allocation was not operationally stable

## Tools

Python, Pandas, NumPy, Gurobi, Matplotlib
